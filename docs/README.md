# 文档首页

这是一个由文件夹驱动的文档站点示例。

把新的 `.md` 文件放入 `docs/` 或任意子目录，刷新页面后它会自动出现在左侧导航中。目录层级会保留在导航中，文件名可以通过 Markdown 标题或 front matter 自定义。

> [!NOTE]
> 页面只读取 Markdown 内容，站点品牌、顶部导航和侧边栏图标由当前目录下的 `docs.config.json` 控制。

## 你可以从这里开始

- 阅读[安装说明](getting-started/installation.md)。
- 查看[如何编写文档](guides/writing-docs.md)。
- 使用顶部搜索框搜索全部 Markdown 正文。

## 支持的内容

| 内容 | 支持情况 |
| --- | --- |
| 标题、段落、列表 | 支持 |
| 代码块与复制 | 支持 |
| 表格、引用、链接 | 支持 |
| 相对图片与 Markdown 链接 | 支持 |
