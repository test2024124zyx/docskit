# 全文搜索

点击顶部的搜索框，输入关键词即可搜索文档标题、相对路径和正文。隐藏文档不会出现在搜索结果中，多个关键词需要同时出现在同一篇文档里。

搜索结果会显示文档标题、路径和命中片段，并高亮关键词。标题、路径和章节命中会获得更高权重，最多显示 30 条结果；点击结果可直接定位对应章节。代码块里的接口路径、请求头和错误码同样可搜索。动态和静态模式使用同一个搜索实现。

## 快捷操作

- 按 `Ctrl K`（macOS 使用 `⌘ K`）打开搜索框。
- 输入关键词后使用 `↑` 和 `↓` 选择结果。
- 按 `Enter` 打开选中的文档，按 `Esc` 关闭搜索框。

文档目录发生变化后，DocsKit 会重新建立索引。修改文档内容后刷新页面，再进行搜索即可看到最新内容。

动态服务的 HTTP 合同与在线调试见[查询文档接口](http/search.md)。
